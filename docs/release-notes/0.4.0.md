## webForCore-thirdparty 0.4.0

The first release. webForCore ships only Microsoft assemblies from 0.4.0 on; the third-party libraries it shipped
before move here, with the same package IDs:

- `webForCore.WebActivatorEx` (was in webForCore 0.3.0 and part of the `webForCore` package): reference it
  explicitly if the application uses WebActivatorEx (Unity.Mvc, Ninject.MVC, StructureMap.MVC, ...).
- `webForCore.AjaxControlToolkit`, `.StaticResources`, `.HtmlEditor.Sanitizer` (were in webForCore 0.1.0–0.3.0).

Built and tested against webForCore 0.3.0.
