## webForCore-thirdparty 0.4.1

- **New: `webForCore.WebActivator`.** It's WebActivator 1.x, written from its documented API. That's the package
  before WebActivatorEx, which MVC 3-era packages such as Ninject.MVC3 2.x bring.
  - The original's start methods never run on webForCore, for the same reason as WebActivatorEx's (webForCore issue
    #21): it finds them with `Assembly.LoadFrom`.
  - Found migrating Subtext in the smoke test.
  - Reference it next to the original package, which it replaces in the build.

Built and tested against webForCore 0.3.0, and with 0.4.0.
