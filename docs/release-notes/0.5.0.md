## webForCore-thirdparty 0.5.0

- **.NET 10 LTS.** The packages target `net10.0` and are built against webForCore 0.7.0, which moved to .NET 10.
  0.4.x target .NET 11 RC, and on .NET 10 NuGet takes them without an error (their `buildTransitive` targets count as
  compatible) but uses none of their assemblies: an application then runs the original WebActivatorEx, whose start
  methods don't run.
- **AjaxControlToolkit** no longer references `webForCore.Drawing.Common`, which webForCore 0.7.0 replaced with
  drawingForCore's packages; System.Drawing comes through `webForCore`. Builds need drawingForCore's packages next to
  webForCore's (`tools/fetch-webforcore.sh` downloads both).
- **NuGet feed.** The packages are on a feed on GitHub Pages,
  https://xforcore.github.io/webForCore-thirdparty/index.json, rebuilt after each release from the latest five, as
  webForCore's and drawingForCore's are. Add it to `nuget.config` instead of downloading the release's packages.
- The smoke test runs its application under `webforcore-host`, as applications run from webForCore 0.7.0.

Built and tested against webForCore 0.7.0 and drawingForCore 0.2.0.
